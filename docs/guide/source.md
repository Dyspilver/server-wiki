# 📜服务器来源
---
## 1.💡灵感
不知道你在游玩minecraft的时候会不会烦恼，击杀坚守者为什么不会像凋零一样掉落独有的掉落物？平凡的药水和粘稠的药水有什么用？火把花，瓶子草的作用？末地更新？

Mojang在原版minecraft里留下了大量的空白，很多物品并没有实际作用，这在很多玩家眼里是无用的，所以我就想，假如有一个服务器，能把Mojang这些无用的更新变的有用呢？于是 DVR 就这样诞生了。

## 2.✨服务器名称
服务器的全称为 Deep Vanilla Realms，简称 DVR，其中的"D"代表"deep"，"V"代表"Vanilla"，"R"则是"Realms"。机翻的话就是深度香草领域，eee这太生硬了，但其实"Vanilla"在mc中代表"原版"的意思，"Realms"则是"领域、世界"，"DVR"就是一个深度还原并强化原版的世界，与我们的理念相符合。
